# Support

## Before contacting support
1. Open **Diagnostics** (System → Diagnostics) and press **Copy report**.
2. Take a backup (**Backup now**) so nothing can be lost while debugging.
3. If the app looks stale after an update, press **Update** in the app or hard-refresh.

## Common fixes
| Symptom | Fix |
|---|---|
| New features not visible | In-app Update button, or hard refresh (service worker cache) |
| Sync stuck / errors | Cloud → Error doctor → check log; press **Repair local DB** |
| Cloud table missing | Supabase → run the SQL shown on the Cloud screen |
| Slow product search | Use the Lite catalogue, or run Data Doctor to clean duplicates |
| Printer prints wrong width | Settings → Printing → paper size 58mm / 80mm / A4 |
| Storage warning | Diagnostics → Backup, then clear old sync logs |

## Channels
- WhatsApp: business hours, fastest for shop-floor issues.
- Email: include the diagnostic report and a screenshot.
- Enterprise customers: SLA response times per contract.
