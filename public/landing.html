Questions shopkeepers ask

Internet band ho jaye to?

Sab kaam karta rahega. Billing, stock, khata — sab device par local hai. Internet aate hi cloud sync khud ho jata hai.

Mera data kahan jata hai?

Aapke device par. Koi tracking, koi analytics nahi. Cloud tabhi jab aap khud apna Firebase/Supabase jodein.

Purana data import hoga?

Haan — JSON/CSV import, ya poora backup restore. 27,000+ products bhi smooth chalte hain.

Kitne device chala sakte hain?

Offline unlimited (har device apna data), aur cloud jodne par sab devices ek hi data par live sync.
